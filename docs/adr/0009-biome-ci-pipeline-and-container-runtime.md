# Biome 2 guardrails, GitHub Actions CI pipeline, and Node 24 container runtime

We standardize code quality on Biome 2.x (`@biomejs/biome` `^2.6.x` with `css.parser.tailwindDirectives: true`, `nursery/useSortedClasses`, `style/noRestrictedImports` FSD layer/slice overrides, `style/noProcessEnv`, `style/useFilenamingConvention`, and `a11y` rules) paired with `@effect/language-service` in `tsconfig.json`. We gate PRs and default-branch pushes in `.github/workflows/ci.yml` on Node `24` + `pnpm@10.19.0` across a `verify` job (`pnpm generate:api` Orval drift check, `pnpm typecheck`, `pnpm biome ci .`, `pnpm test`, `pnpm build`, `src/routeTree.gen.ts` drift check, and secret-gated Sentry/Datadog hidden source-map uploads on default-branch pushes) and a `docker` job (`docker compose config --quiet`, `docker build`, and container `/health` + `/showcase` SSR smoke checks). We package the application in a 5-stage `node:24-slim` `Dockerfile` (`base` → `deps` → `build` → `prod-deps` → `runtime` as non-root `USER node`) running a zero-extra-framework `server.mjs` entry that serves `./dist/client` static assets, `/health`, an optional `/api/*` and `/_storage/*` same-origin reverse proxy to `API_INTERNAL_URL`, and `dist/server/server.js`'s WinterCG `fetch` handler with graceful `SIGTERM`/`SIGINT` draining, paired with a `web`-focused `docker-compose.yml` (`API_INTERNAL_URL: ${API_INTERNAL_URL:-http://host.docker.internal:9999}`).

## Considered Options

- **ESLint 10 (`@antfu/eslint-config`) + Prettier + `eslint-plugin-better-tailwindcss`**: Rejected because Biome 2.x executes 50–100x faster as a single Rust binary, natively parses Tailwind v4 CSS-first directives (`@theme inline`, `@utility`, `@custom-variant`) and sorts classes via `useSortedClasses`, includes 30+ `a11y` rules out of the box, and enforces unidirectional `ADR-0001` layer boundaries via `style/noRestrictedImports` without 45+ transitive lint packages.
- **Running `vite preview` as the production container entrypoint or using `node:24-alpine`**: Rejected because `vite preview` is a local preview tool that lacks `/health` probes, same-origin `/api/*` + `/_storage/*` reverse-proxying for `API_INTERNAL_URL`, immutable `/assets/*` cache headers, and graceful `SIGTERM` connection draining, while `node:24-slim` aligns with `hono-open-api` `ADR-0012` and avoids musl/Alpine DNS and native-module edge cases.
- **Unconditionally running Sentry/Datadog source-map upload plugins or shipping public `.map` files**: Rejected because public source maps expose application source code in production and unconditional upload plugins break local/fork builds without vendor secrets; setting `build.sourcemap: "hidden"`, gating `@sentry/vite-plugin` and `@datadog/datadog-ci sourcemaps upload` strictly on `SENTRY_AUTH_TOKEN` / `DATADOG_API_KEY`, and deleting `dist/**/*.map` before packaging the runtime image keeps builds reproducible everywhere.
- **Duplicating `hono-open-api`'s full backend services (`redis`, `s3`, `s3-init`, `migrate`, `api`, `worker`) inside `tanstack-open-api/docker-compose.yml`**: Rejected because duplicating backend Compose definitions across two repositories creates configuration drift; defaulting `web`'s `API_INTERNAL_URL` to `http://host.docker.internal:9999` (with `extra_hosts: ["host.docker.internal:host-gateway"]`) connects seamlessly to a host-running `hono-open-api` stack while remaining overridable (`http://api:9999`) on shared Docker networks.

## Consequences

- `package.json` pins `"packageManager": "pnpm@10.19.0"` and `"engines": { "node": ">=24" }`, and exposes standardized scripts: `dev`, `build`, `start` (`node server.mjs`), `serve` (`vite preview`), `typecheck` (`tsc --noEmit`), `lint` (`biome check .`), `lint:fix` (`biome check --write .`), `test` (`vitest run --project unit`), `test:watch`, `test:coverage`, `generate:api` (`orval`), `sync:api` (fetch `http://localhost:9999/doc` to `./openapi.json` and run `orval`), and `prepare` (`effect-language-service patch`).
- `biome.json` force-ignores generated and build outputs (`!!dist`, `!!coverage`, `!!src/routeTree.gen.ts`, `!!src/shared/api/generated`, `!!openapi.json`, `!!tsconfig.tsbuildinfo`), restricts `process.env` / `import.meta.env` to `src/shared/config/env.ts` and root config/server entry files, enforces `kebab-case` filenames outside `src/routes/**`, and enforces `app` → `routes` → `features` (isolated per slice) → `shared` imports.
- `.github/workflows/ci.yml` fails fast if either `src/shared/api/generated/**` (after `pnpm generate:api`) or `src/routeTree.gen.ts` (after `pnpm build`) has uncommitted diffs or untracked files, and verifies the production Docker image by booting `tanstack-open-api-starter:ci` and asserting `200 OK` on `/health` and `/showcase`.
- `server.mjs` streams `/api/*` and `/_storage/*` requests to `API_INTERNAL_URL` when configured—preserving `cookie`, `authorization`, `x-request-id`, `traceparent`, `Set-Cookie`, binary uploads/downloads, and unbuffered `text/event-stream` SSE (`X-Accel-Buffering: no`)—so browser sessions work same-origin (`VITE_API_URL=""`) in both local Vite dev and containerized deployments.
