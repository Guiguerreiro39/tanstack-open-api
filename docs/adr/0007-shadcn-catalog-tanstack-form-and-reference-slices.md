# Complete `new-york-v4` `shadcn/ui` catalog, `useAppForm` `Field` composition, and reference slices (`auth`, `tasks`, `files`, `showcase`)

We ship all 60 applicable `shadcn/ui` `new-york-v4` UI primitives as flat React 19 function modules (`data-slot` instrumentation, no `React.forwardRef`) in `src/shared/ui/<name>.tsx` (plus `src/shared/lib/hooks/use-mobile.ts` and three starter-specific shells: `app-shell.tsx`, `can.tsx`, and `router-feedback.tsx`), standardizing on the unified `radix-ui` package alongside `@base-ui/react` (`combobox`), `cmdk`, `vaul`, `react-day-picker@^9`, `input-otp`, `react-resizable-panels@^4`, `recharts@^3.8`, and `sonner` wired to `useTheme()` (`src/shared/lib/theme.ts`). We replace the registry's `react-hook-form`-coupled `form.tsx` with a TanStack Form v1 + Effect Standard Schema (`Schema.standardSchemaV1`) composition module (`src/shared/ui/form.tsx`) built on `shadcn/ui`'s `field.tsx` (`useAppForm`, `withForm`, `withFieldGroup`, `applyServerValidationErrors`), and implement four end-to-end `Feature Slice`s paired with `hono-open-api`: `auth` (`/login.tsx` + `/_app/settings.tsx` profile & RBAC inspector), `tasks` (`/_app/tasks.tsx` with live SSE status badge, `<Can>`-gated `"own" | "all"` `Resource Scope`, and optimistic CRUD), `files` (`/_app/files.tsx` with `Auto | Multipart | Presigned` upload mode selection, XHR determinate byte progress + abort, `409`/`413`/`422` recovery, and stream/signed-URL downloads), and a code-split `showcase` (`/showcase.tsx` with a Live Theme & Token Studio and 7-category interactive component gallery).

## Considered Options

- **Keeping `shadcn/ui`'s default `form.tsx` (`react-hook-form` + `@hookform/resolvers` + `zod`) or repeating raw `<form.Field>` / `<form.Subscribe>` blocks per form**: Rejected because installing `react-hook-form` and `zod` duplicates `@tanstack/react-form` and `effect/Schema`, while raw `<form.Field>` repetition (as in `forklore-fe`'s 150–180 line auth forms) scatters `aria-invalid`, `aria-describedby`, and `StandardSchemaV1Issue` formatting across every slice.
- **Validating forms on every `onChange` keystroke from initial focus or referencing hidden error elements unconditionally in `aria-describedby`**: Rejected because `onChange` validation yells at users before they finish typing their first entry, and static `aria-describedby` references cause screen readers to announce hidden error nodes or empty required inputs as invalid on page load.
- **Using `fetch()` for the presigned storage `PUT` or hiding multipart vs presigned upload modes**: Rejected because standard browser `fetch()` does not expose upload byte-progress events (`ReadableStream` request bodies lack universal browser progress support), and exposing `Auto | Multipart | Presigned (3-Step)` lets developers test both `POST /api/v1/files` (`<= 10 MB`) and `POST /api/v1/files/presign` → `PUT uploadUrl` (`/_storage/object` or S3) → `POST /api/v1/files/{id}/complete` (`<= 100 MB`) at any file size.
- **Grouping `src/shared/ui/` into category subdirectories or gating `/showcase` behind authentication**: Rejected because nested subdirectories break `npx shadcn@latest add` flat alias resolution in `components.json` (`"ui": "@/shared/ui"`), and gating `/showcase` behind `/_app.tsx` prevents evaluators from inspecting the design system and `Theme Preset` switcher before signing in.

## Consequences

- `src/shared/ui/` contains the 60 `new-york-v4` primitives, `form.tsx` (exporting `useAppForm`, `withForm`, `withFieldGroup`, `applyServerValidationErrors`, and `Field Primitive`s: `TextField`, `TextareaField`, `PasswordField`, `NumberField`, `SelectField`, `CheckboxField`, `SwitchField`, `RadioGroupField`, `FieldErrors`, `SubmitButton`, `FormErrorBanner`), `theme-switcher.tsx`, `app-shell.tsx`, `can.tsx`, and `router-feedback.tsx` (`DefaultErrorBoundary` calling `router.invalidate()` and `DefaultNotFound`).
- Every `Field Primitive` in `src/shared/ui/form.tsx` defaults to `revalidateLogic({ mode: "submit", modeAfterSubmission: "change" })` + `validators: { onBlur: Schema.standardSchemaV1(schema), onDynamic: Schema.standardSchemaV1(schema) }`, initializes `aria-invalid={isInvalid ? "true" : "false"}` (never unset), appends the error element `id` to `aria-describedby` only while `isInvalid` is true (after any persistent hint `id`), moves focus to the first invalid control on failed submit, normalizes both `StandardSchemaV1Issue` objects and strings, and decodes transformed values via `Schema.decodeSync(schema)(value)` in `onSubmit`.
- `src/features/files/` pre-validates non-empty files, size caps (`10 MB` multipart, `100 MB` presigned), and `ALLOWED_MIME_TYPES`, runs presigned `PUT uploadUrl` via `XMLHttpRequest` (`withCredentials = false`, `Content-Type: file.type`) wired to a semantic `<progress>` bar and `AbortController`, supports step-level retry (`PUT` + `/complete` on `409 OBJECT_NOT_FOUND` or transient error; full re-presign on `409 UPLOAD_EXPIRED`), and retries downloads with short backoff if a newly completed file returns `409 FILE_PENDING`.
- `/showcase.tsx` is code-split via TanStack Router lazy route loading so chart (`recharts`), calendar (`react-day-picker`), and split-pane (`react-resizable-panels`) demos never increase the initial bundle of `/login` or `/_app/*`.
